# Fellix font files

The whole app and the prototypes use **Fellix** (sizes and weights unchanged: 400, 500, 600, 700).
Fellix is a commercial typeface, so the font files are not in this repository. Add your licensed web fonts here:

    Fellix-Regular.woff2    (400)
    Fellix-Medium.woff2     (500)
    Fellix-SemiBold.woff2   (600)
    Fellix-Bold.woff2       (700)

Until the files exist (or Fellix is installed on the viewer's computer), the pages fall back to the previous
fonts (Figtree for text, Bricolage Grotesque for headings) so nothing breaks.

Check the font licence covers web use (self-hosting) before deploying.
