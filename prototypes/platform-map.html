Architecture

One Next.js app serves the pages and the API. Pricing runs on the server so the browser can never set its own total.

Browser
Next.js 15 App Router, React 19, Tailwind 4. Renter, owner and admin screens. Pages fetch from /api.
API
Route handlers in app/api. Signed HttpOnly cookie session (lundro_session, 14 days), scrypt password hashes.
Domain
lib/pricing.ts (boat, extras, captain, fee, NC tax split), lib/catalog.ts (add-ons), lib/boats.ts (listing shape).
Data
PostgreSQL 16 through Prisma. Money stored as integer cents. Migrations in prisma/migrations.
Ops
GitHub Actions (tests, typecheck, build against Postgres), Dockerfile, Vercel config.

Pricing and North Carolina tax

One function, computeQuote, is used by checkout, the confirmation page and the booking API. Example: half day, captain for 4 hours, tube and cooler, 10% service fee.

Rules

  • Boat time: 3% state tax, capped at $1,500 of tax
  • Rented gear: 4.75% state + 2% county + 1.5% transit
  • Captain ($50/hr) and the service fee are untaxed for now
  • Federal and state agencies can be exempt
  • Security deposit: $500 hold

Run and deploy

Local

docker compose up -d db
cp .env.example .env
npm install
npm run db:migrate
npm run db:seed
npm run dev

Production

  • Set DATABASE_URL and AUTH_SECRET
  • Run npm run db:deploy on release
  • Vercel, Docker or plain Node
  • CI runs tests, typecheck and build on every push
