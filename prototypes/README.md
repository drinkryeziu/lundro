# Clickable prototypes

Self-contained HTML files with sample data (no build step, no backend). Open in any browser.

- `renter.html`: home, Lake Norman, search with map, boat page, 6-step checkout, confirmation
- `owner-admin.html`: owner signup, 11-screen owner dashboard, admin review queue (use the switcher at the bottom right)
- `platform-map.html`: architecture, screens, data model, API and roadmap overview

Built from the design PDFs. The real app lives in `app/`.
