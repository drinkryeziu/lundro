# Clickable prototypes

Self-contained HTML files with sample data (no build step, no backend). Open in any browser.

- `lundro-prototype.html`: the whole product in one page. Renter site (home, Lake Norman, search with map, boat page, 6-step checkout, confirmation), owner signup, 11-screen owner dashboard and the admin review queue. Switch views with the bar at the bottom; Log in / List your boat on the renter site open the owner views.
- `platform-map.html`: architecture, screens, data model, API and roadmap overview

Built from the design PDFs. The real app lives in `app/`.
